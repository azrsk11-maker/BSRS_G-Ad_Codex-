## Verification boundaries

`python docs/audit/private-query-triage-counts-2026-11-08/verify_counts.py` checks pinned public counts, strict field types, arithmetic, historical-source linkage, zero-authority controls and optimization/golden artifact identity. Default CI cannot reproduce private inputs, judge phrase semantics, prove disclosure safety or certify source authenticity.

The optional paired `--source` and `--proposals` arguments reproduce the privately pinned source/proposals, exact private workbench bytes and count summary. Keep both inputs outside the public repository. Output is scalar-only; failure output never prints inputs, paths or exception details. Private reproduction also does not complete the unresolved business/disclosure gates.
